# Конвейер документов для плоттера

Проект на C++20 подготавливает шрифт и превращает документ в команды для плоттера. Доступны два отдельных запуска через [Makefile](Makefile).

## Что нужно установить

Для команд ниже нужны `make`, `g++` или `gcc` с поддержкой C++20, системные библиотеки FreeType и zlib. CMake не требуется. Команды выполняются из корня проекта.

## Подготовка файлов

1. Положите шрифт `.ttf` или `.otf` в папку `fonts/`.
2. Положите документ `.md`, `.txt`, `.docx` или `.svg` в папку `docs/`.
3. Сначала подготовьте шрифт, затем запустите обработку документа.

Например, для файлов `fonts/почерк.ttf` и `docs/1.md` выполните:

```bash
make font почерк.ttf
make doc 1.md
```

Во всех командах второй аргумент — **только имя файла**, без `fonts/` или `docs/`. Расширение можно опустить: `make font почерк` и `make doc 1` тоже работают. Если файлов с одинаковой основой имени несколько, укажите расширение. В имени файла для этих команд не должно быть пробелов.

## Подготовка шрифта

```bash
make font почерк.ttf
```

Команда при необходимости собирает программу и создаёт `font-cache/почерк/почерк.pfc`. Повторный запуск обновляет этот файл. Исходный шрифт остаётся в `fonts/`. По умолчанию берутся символы из `examples/centerline_glyph_corpus.txt`; свой список символов можно передать как `make font почерк.ttf CHARS=путь_к_файлу`.

## Обработка документа

```bash
make doc 1.md
```

Команда собирает программу и записывает результат в `build/1/`. Внутри находятся `output.gcode`, отчёт и файлы страниц. Предпросмотр первой страницы откройте из `build/1/pages/page-001/plotter-preview.svg`. Перед отправкой команд плоттеру проверьте этот предпросмотр.

По умолчанию используется лист А4. Для А5:

```bash
make doc 1.md PAGE=A5
```

При обработке траектории автоматически упрощаются и оптимизируются. Если документ пересекает запретную зону листа А5, программа сообщит об ошибке; в таком случае используйте А4 или измените параметры листа.

Если в `font-cache/` подготовлен только один шрифт, он выбирается автоматически. Если шрифтов несколько, укажите нужный:

```bash
make doc 1.md FONT=почерк
make doc 1.md FONT=почерк PAGE=A5
```

Значение `FONT` — имя подпапки в `font-cache/`, без пути и `.pfc`. Если готового шрифта ещё нет, сначала выполните `make font имя_шрифта`. Показать короткую подсказку можно командой `make`.

## Настройки и ручной запуск

Параметры листа находятся в `configs/layout.yaml`, параметры плоттера — в `configs/machine.yaml`. Команда `make doc` использует настройки А4 из `modules/document/fixtures/machine-a4.yaml`; для А5 — `configs/machine.yaml`.

Команды Make собирают только нужную программу. Для ручной сборки без CMake:

```bash
make build/modules/fontc/fontc
make build/modules/document/plotter-doc
```

После сборки полный список параметров можно посмотреть так:

```bash
build/modules/fontc/fontc --help
build/modules/document/plotter-doc --help
```
