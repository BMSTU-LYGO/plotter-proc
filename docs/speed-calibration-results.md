# Результаты калибровки движения

Сначала выполните dry-run без касания бумаги, затем `calibrate-pen` и
`calibrate-speed`. Профиль `safe` остаётся стандартным до трёх успешных
физических прогонов.

## Карта speed-test

- пять горизонтальных линий сверху вниз: draw 1000, 1250, 1500, 1750, 2000 мм/мин;
- пять диагоналей слева направо: settle 100, 60, 40, 20, 0 мс;
- файл заканчивается гарантированным подъёмом пера.

```bash
.venv/bin/python -m plotter_processor calibrate-pen --motion-profile safe
.venv/bin/python -m plotter_processor calibrate-speed --motion-profile safe
```

| Проверка | safe | balanced | fast |
|---|---|---|---|
| Ручка не касается бумаги при travel | ☐ | ☐ | ☐ |
| Начало линии не пропущено | ☐ | ☐ | ☐ |
| Нет клякс и потери шагов | ☐ | ☐ | ☐ |
| Прямые и петли не дрожат | ☐ | ☐ | ☐ |
| Фактическое время 50 слов | | | |

Не уменьшайте `up_z_mm` и не выбирайте `fast` по умолчанию до физической проверки.
